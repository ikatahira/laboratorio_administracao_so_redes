💻Por que isso importa: do Hardware ao Sistema Operacional de Rede

Todo o trabalho de hoje tem um motivo prático além da prova: nenhum Sistema Operacional de Rede é instalado "no escuro". Antes de instalar o Ubuntu Server/Firewall (Semana 5) ou o Windows Server (Semana 12), o administrador precisa levantar os recursos de hardware disponíveis e confirmar se atendem aos requisitos mínimos da instalação — exatamente a habilidade que a disciplina teórica de Administração de Sistemas Operacionais de Redes exige: "identificar recursos de hardware necessários para a instalação de sistemas operacionais de rede".

🔗 Conexão direta com o cronograma:
• Semana 5 — instalação de Ubuntu Firewall (2 NICs), Ubuntu Server e Ubuntu Desktop
• Semana 12 — instalação do Windows Server e planejamento do Server Manager
Sem saber ler a placa-mãe, a RAM instalada e as placas de rede do gabinete, não é possível planejar nenhuma dessas instalações.
